Your hands are free now

Works with any webcam. A wizard learns your blink from a few practice takes.

  1. Download. Unzip the file anywhere.
  2. Run eyeokuri.exe. Keep your eyes open for 2 seconds.
  3. Blink in your game. The next line appears.
Download for Windows

The first run downloads a 4 MB face model, so be online once. Windows might warn about an unknown publisher because the app is not signed. Select More info, then Run anyway.

Prefer Python? Install from source
# needs Python 3.11+ git clone https://github.com/lulalala/visual-novel-eye-controller cd visual-novel-eye-controller python -m venv .venv && .venv\Scripts\activate pip install -e . eyeokuri-gui

Make it yours

The gesture wizard learns your blink from a few practice takes. You can also turn on nod up and nod down for the arrow keys, or send space, a click or a scroll instead of Enter.
